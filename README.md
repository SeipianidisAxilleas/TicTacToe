Данное приложение предназначено для игры в крестики нолики двумя игроками.
Для начала игры нужно запустить приложение.
Для того чтобы запустить игру надо войти по данному пути tictactoe\tictactoe\bin\Debug и два раза нажать на файл tictactoe. 
После запуска приложения появляется окно WindowsForms в котором находятся 9 кнопок которые являются полями для меток,текст Ход рядом с которым будет высвечивается количество ходов,а в низу находится кнопка перезапуска которая позволяет перезапустить игру.
Для того чтобы начать играть ван необходимо выбрать на каком квадрат вы хотите оставить метку и нажать.
Для того чтобы выиграть одному из игроков необходимо собрать горизонтальную,вертикальную или диагональную линию с метками только одного игрока. 
Ход в самой игре поочередной, сначала ходить игрок Х а затем игрок О.
